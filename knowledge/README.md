# Knowledge base

Markdown files in this folder are fed to the "Ask" chat as context, on top of
the case studies in `content/` and the profile in `src/data/resume.tsx`.

- One topic per file (`process.md`, `faq.md`, `tools.md`, ...).
- Optional frontmatter: `title`. Without it, the file name is used.
- This README is excluded.
- Write in plain first-person facts. Anything here can be quoted to visitors.
